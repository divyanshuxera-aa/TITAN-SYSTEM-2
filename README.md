# TITAN SYSTEM

Responsive gaming-support portal built with React, TypeScript, Vite and Capacitor.

## Local development
```bash
npm install --legacy-peer-deps
npm run dev
```

## Android APK
Push the project to the `main` branch or manually run **Build TITAN SYSTEM Android APK** in GitHub Actions. On success, download the `titan-system-debug-apk` artifact from the workflow run.

The workflow creates the Android project if it is missing, syncs Capacitor, builds a debug APK, and uploads it.

## Important
The support form is a front-end demo only. It does not send or store data and does not bypass game account restrictions. Connect a secure, approved backend before accepting real support requests. This independent project is not affiliated with a game publisher.
